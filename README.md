# lite-mods

Вайб-кодинг готовых блоков Ида.Лайт: анимации, правки, модернизация без доступа к бэку.

## Установка на сайт (один раз)
Админка сайта → кастомные скрипты (в `<head>`, на все страницы):

```html
<script src="https://asermiajko.github.io/lite-mods/loader.js" defer></script>
```

### Сайт в режиме превью (dev-lite.ru)
На превью-сайтах (`is_preview_mode: true`) платформа **не выполняет** глобальные скрипты из настроек сайта. Тогда на каждую нужную страницу добавляется HTML-блок (лучше в самый низ):
- вкладка **JS**:
  ```js
  (function () {
    if (window.LiteMods) return;
    var s = document.createElement('script');
    s.src = 'https://asermiajko.github.io/lite-mods/loader.js';
    document.head.appendChild(s);
  })();
  ```
- вкладка **HTML**: `<div hidden></div>`. Пустой HTML нельзя: платформа подставит картинку-заглушку `default_html.jpg` высотой ~1500px.

Глобальный тег оставить: на боевом сайте он заработает сам, а повторно загрузчик не подключится.

## Как пользоваться
Пишешь агенту (Claude Code в этой папке), например:
> в InfraBlock__ClassicType5 сделай карточки покрупнее и анимацию появления

Агент правит патч и показывает превью. Пишешь «ок, публикуй», и через ~1–2 минуты изменение на сайте.

| Адрес | Что видно |
|---|---|
| `сайт/` | бой: опубликованные патчи |
| `сайт/?dev=1` | черновик с `localhost:3400` (нужен запущенный `python3 dev.py`, Chrome) |
| `сайт/?dev=0` | выйти из черновика |
| `сайт/?nomods=1` | оригинал без патчей |

## Структура
```
loader.js                  — загрузчик (подключается в админке)
sites/<hostname>.json      — какие патчи включены на сайте (источник)
sites/<hostname>.js        — собранный файл сайта: все патчи в одном (его грузит loader.js)
blocks/<Блок>/style.css    — стили патча
blocks/<Блок>/script.js    — JS патча
blocks/<Блок>/snapshot.txt — структура блока (для агента)
blocks/<Блок>/notes.md     — что и когда изменено
dev.py                     — локальный сервер черновиков (:3400)
tools/build.py             — сборка sites/*.js, dist/*.bundle.js (вставка в админку), --preview для превью
tools/snapshot.js          — снять структуру блока со страницы
publish.sh                 — опубликовать
```

## Запасной вариант без GitHub Pages
`python3 tools/build.py` → содержимое `dist/<hostname>.bundle.js` вставить во вкладку JS в админке (обернуть в `<script>…</script>`, если поле ждёт HTML).
