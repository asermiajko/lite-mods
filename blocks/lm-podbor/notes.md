# lm-podbor — «Подбор квартиры под вашу жизнь»

Свой блок (не патч штатного): монтируется в HTML-блок страницы `/podbor`.
- Вкладка **HTML**: `<div class="lm-podbor"></div>`
- Вкладка **JS**: тот же загрузчик, что и на главной (см. README).

## Флоу
1. Цель: жить одному / семья / родственники / инвестиции.
2. Уточнение: 2+0, 2+1, 3+; для детей / родителей; стратегии инвестора; для «один» — первая квартира / работаю из дома / простор и вид.
3. Что важно: пресет отмечает потребности (первые три весят вдвое больше), срок переезда, бюджет.
4. Типы планировок, отсортированные по совпадению: «Почему подходит» и «В обмен на». Внутри типа — сравнение квартир по этажу, тишине, пыли, свету, отделке и цене, с пометкой «Лучшая для вас».

Состояние подбора хранится в адресе (`#podbor=…`): ссылкой можно поделиться.

## Данные (2026-10-15)
- Каталог: `/api/realty-filter/residential/real-estates` (постранично по 100), этажность секций — `/api/realty-filter/residential/sections`.
- **Тип** = ЖК + комнатность + евро + площадь в пределах 1,5 м² (кластеризация). Картинки планов привязаны к стояку, а не к планировке, поэтому группировать по ним нельзя.
- Потребности — правила на полях API (`model.js → NEEDS`). Если данных нет, правило возвращает `null` и не считается ни за, ни против.

## Допущения (пока стояки не размечены)
- Окна: улица спального района (1×1), 50–100 м до дороги.
- Тишина: дельты дБ к тихому двору (закрыто: шоссе +8,5, спальник +5,5; открыто: +15 / +11,5) плюс поправка на этаж (1–2: +3, 3–5: +1, 6–12: 0, 13+: −1, у шоссе +1).
- Пыль: база для шоссе по этажам (1 эт. 1,15 → 18+ эт. 0,38), спальник ×0,6, двор ×0,4, Kd по расстоянию.
- Разметка стояков (следующий этап) подставляется через `window.LM_PODBOR_STACKS[host]["<section_id>:<axis>"] = { side, distance, dirs }`.

## Стенд

## Расчёт (2026-10-15, v2)
**Совпадение (процент на карточке типа).** Потребности пресета в порядке важности: первые три ×2, остальные ×1. Срок переезда добавляется отдельно ×2 и никого не сдвигает. Каждая потребность: да = 1, нет = 0, нет данных = 0,5 (нейтрально, полнота данных не даёт бонуса). Итог = взвешенное среднее.

**Лучшая внутри типа.** Планировка у квартир типа одна, поэтому сравниваются факторы квартиры по шкале 0–1: тишина, пыль, свет (нет данных = 0,5), соответствие этажа цели, цена за м² относительно медианы типа (−10% → 1, +10% → 0). Веса — под цель (`PROFILES`): семья, родители, работа из дома, вид, бюджет, инвестиции. Порядок: совпадение (шаг 5%) → факторы (шаг 0,02, меньшая разница неразличима) → цена.

**Объяснение.** Два самых весомых преимущества перед средним по типу. «Выгоднее по цене» — только если лучшая не дороже медианы. Если факторы почти равны (разброс < 0,03), пишем «Квартиры почти одинаковы, выбрали самую выгодную по цене». Если есть дешёвые варианты, говорим, сколько их и что они уступают.
