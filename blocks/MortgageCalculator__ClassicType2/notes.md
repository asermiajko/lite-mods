# MortgageCalculator__ClassicType2 → «Ипотечный навигатор»

Штатный калькулятор заменён своим интерфейсом (уровень L3): заголовок и текст блока остаются из админки, контент штатного блока спрятан.

## Данные
- `GET /api/mortgage/offers/published` (+ `/specs`, `/facets`), обязательный заголовок `x-host: <hostname>`.
- Параметры: `project_id` (`$nuxt.$store.state.site.project.id`), `property_type` (несколько раз), опционально `complex_id`, `program_id`, `price`, `deposit` (в %), `term` (лет), `ignore_priority=false`.
- **Без price/deposit/term** API отдаёт все предложения (`payment: 0`), **с ними** — только подходящие. Загружаем все один раз и считаем сами.
- Стандартные предложения: аннуитет `credit·r/(1−(1+r)^−n)` по `min_rate` и сроку из фильтра совпадает с API до рубля.
- Транши (`type: tranche`, `tranche_calc: legacy_rate_grace`): `special_payment` — платёж в льготный период по `special_min_rate` до `first_tranche_end`, `payment` — по `min_rate`. Точные цифры берём у API с текущими параметрами (через 300 мс после изменения).
- В предложении есть `background_color`, `color_mini` и другие логотипы (`$nuxt.$static.gen(path)`), `program_name`, `min_deposit`, `max_term`, `min_term`, `max_credit_amount`.
- Настройки блока из админки: `root.__vue__.$props` (`complex_id`, `program_ids`, `property_type`, `request_button_form_id`…). Стартовые значения: `$data.values`.

## Что умеет (v1, 2026-10-14)
- Сводка: платёж лучшего подходящего предложения (плавно пересчитывается), сумма кредита, переплата.
- Сортировка: платёж / переплата / ставка / взнос. **Платёж сравнивается по среднему за весь срок**, чтобы транш с коротким льготным периодом не выглядел самым дешёвым.
- По одному предложению на банк. Недоступные не прячутся: серые, с причиной («Нужен взнос от 25% — ещё 195 388 ₽», «Срок до 21 года») и кнопкой «подставить».
- Метка «Выгоднее всего», если подходящих банков больше одного. Полоса платежа в фирменном цвете банка.
- «Оставить заявку» нажимает спрятанную штатную кнопку → открывается штатная форма «Заявка на ипотеку».
- Если API не ответило — навигатор не монтируется, работает штатный калькулятор.
